# 术语索引（Vol. 01）

> 本期出现的关键术语汇总。每个术语只保留“本期理解”层面的定义，后续卷会在需要时进一步细化。

---

## 基础概念

| 术语 | 中文 | 本期理解 |
|------|------|----------|
| Ledger | 账本 | 记录资产归属、余额或其他状态的系统 |
| Asset | 资产 | 具有经济价值的对象 |
| State | 状态 | 系统在某一时刻的完整可观察结果 |
| State Transition | 状态转换 | 从旧状态到新状态的合法变化 |
| Transaction | 交易 | 请求状态发生变化的操作 |
| Centralized | 中心化 | 由中心机构维护和裁决 |
| Decentralized | 去中心化 | 不依赖唯一中央机构 |

---

## 授权与验证

| 术语 | 中文 | 本期理解 |
|------|------|----------|
| Digital Signature | 数字签名 | 用私钥签名、公钥验证的授权机制 |
| Private Key | 私钥 | 用于签名、控制权限的秘密凭证，必须保密 |
| Public Key | 公钥 | 用于验证签名的公开信息 |
| Validation | 验证 | 检查交易是否符合协议规则（余额、冲突、业务条件等） |
| Double Spending | 双重花费 | 同一份数字价值被尝试用于冲突支付 |

## 历史与共识

| 术语 | 中文 | 本期理解 |
|------|------|----------|
| Block | 区块 | 按协议组织起来的一组交易及其相关元数据 |
| Hash | 哈希 | 数据的固定长度摘要，用于完整性结构 |
| Consensus | 共识 | 分布式参与者就有效历史与状态达成共同认识的机制 |
| Confirmation | 确认数 | 交易被后续区块覆盖的层数，反映历史稳定性 |
| Stale Block | 过时区块 | 未成为主历史的有效区块 |

## Bitcoin 相关

| 术语 | 中文 | 本期理解 |
|------|------|----------|
| UTXO | 未花费交易输出 | Bitcoin 中当前仍可被消费的价值输出 |
| Change Output | 找零输出 | 交易中退回给发送方的新 UTXO |
| Mining | 挖矿 | 参与区块生产竞争的过程 |
| Proof of Work (PoW) | 工作量证明 | 通过计算工作建立出块与链选择成本的机制 |
| Mempool | 待处理交易池 | 已验证但尚未被打包进区块的交易集合 |

## Ethereum 相关

| 术语 | 中文 | 本期理解 |
|------|------|----------|
| Account Model | 账户模型 | 以持续存在的账户作为状态基本单元的模型 |
| EOA | 外部账户 | Externally Owned Account，由私钥控制、无代码的账户 |
| Contract Account | 合约账户 | 由代码控制、可有自己存储的账户 |
| Smart Contract | 智能合约 | 部署在链上、按协议规则执行的程序 |
| Gas | Gas | 对计算与资源消耗进行计量的单位 |
| Gas Price | Gas 价格 | 单位 Gas 的价格 |
| Fee | 费用 | 用户为交易执行支付的经济成本 |
| Shared State Machine | 共享状态机 | 网络共同维护并验证的状态转换系统 |

## Solana 相关

| 术语 | 中文 | 本期理解 |
|------|------|----------|
| Account（Solana） | Solana 账户 | 链上承载状态和数据的基本单元 |
| Program | 程序 | Solana 中执行链上业务逻辑的代码 |
| Instruction | 指令 | 交易中请求某个 Program 执行具体操作的描述 |
| Explicit Account Access | 显式账户访问 | 交易明确声明要读写的 Accounts |
| Sealevel | Sealevel | Solana 的并行执行运行时 |
| Proof of History (PoH) | 历史证明 | 帮助建立可验证时间顺序的机制 |
| State Dependency | 状态依赖 | 交易因访问相同状态而产生的执行约束 |
| Parallel Runtime | 并行运行时 | 根据依赖关系调度交易执行的运行时 |

## 使用建议

- 不要试图一次背下所有术语。先理解它解决的问题，再记住名称。
- 遇到混淆时，优先回到两条分界线：
  - **Consensus vs Execution**
  - **Program（代码）vs Account（状态）**
- 后续各期会在需要时对同一术语做更精细的展开。
