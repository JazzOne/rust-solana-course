# 03 · Bitcoin 到底解决了什么？

> 本章目标：理解 Bitcoin 作为第一个大规模运行的去中心化数字价值系统，它选择了怎样的状态模型（UTXO），又如何用 Proof of Work 解决“谁来决定下一批交易进入公共历史”的问题。

前两章我们建立了共同记账的基本框架。现在来看历史上第一个给出完整可运行答案的系统——Bitcoin。

## 3.1 Bitcoin 的核心问题声明

> **能不能在没有中央银行或支付公司的情况下，让陌生人之间可靠地转移数字价值？**

Bitcoin 给出了第一个完整、可运行的答案。

## 3.2 BTC 到底在哪里？

钱包主要保存私钥；网络维护 UTXO 状态。
