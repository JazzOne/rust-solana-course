# 全书路线图

这套课程沿着三条线同时推进：

| 线路 | 目标 |
| --- | --- |
| 世界观线 | 建立对钱、账本、区块链、共识和 Solana 的整体理解 |
| 技术线 | 用 Rust 真正构建 Solana 应用和后端系统 |
| 商业线 | 学会从技术能力走向产品、服务与商业验证 |

## Phase 0 · 加密货币世界观

钱 → 账本 → 数字签名 → 区块链 → Bitcoin → Ethereum → Solana

## Phase 1 · Solana 基础模型

SOL → Lamports → Wallet → Address → Account → Balance → Validator

## Phase 2 · Wallet / RPC / Transaction

RPC → Keypair → Transaction → Instruction → Signature → Confirmation

## Phase 3 · Rust + Anchor

Program → Account → Instruction → Context → IDL → Testing

## Phase 4 · PDA / CPI / Token

PDA → Seeds → CPI → SPL Token → ATA → Token-2022

## Phase 5 · Payment Product

Invoice → Payment → Webhook → Indexer → PostgreSQL → Queue / Retry → Monitoring

## Phase 6 · Security

Signer → Owner → PDA validation → Account validation → CPI security → Upgrade authority → Key management

## Phase 7 · Solana Internals

Sealevel → Compute Units → Priority Fees → Transaction Pipeline → Validator → Consensus → Runtime

## Phase 8 · 商业化

技术服务 → 开发者工具 → SaaS → dApp → 支付基础设施 → Grants / Hackathons → 机会验证
