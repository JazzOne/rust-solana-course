## 这不是一本 API 速查表

我们不从“先背 50 个 Web3 术语”开始，而是从问题开始：**为什么需要区块链？为什么 Bitcoin 这样设计？为什么 Ethereum 又换了一套模型？为什么 Solana 最终选择了这样的架构？**

读懂这些问题之后，再写代码。
